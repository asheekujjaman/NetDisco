First Time Manual Discovery
---------------------------
Run discovery from the core switch first:

~/bin/netdisco-do discover -d 10.10.99.1

If LLDP/CDP is enabled between switches, Netdisco may discover AS2, AS3, and AS4 automatically.
If they are not discovered automatically, discover them manually:

~/bin/netdisco-do discover -d 10.10.99.1
~/bin/netdisco-do discover -d 10.10.99.2
~/bin/netdisco-do discover -d 10.10.99.3
~/bin/netdisco-do discover -d 10.10.99.4

Then collect MAC and ARP information:

~/bin/netdisco-do macwalk
~/bin/netdisco-do arpwalk

Network Information

Management switch network:

Important Concept
-----------------
Use the management subnet for Netdisco device discovery:
- 10.10.99.0/24
Do not use normal PC VLAN subnets for device discovery unless those IPs are actual switch/router management IPs.

Netdisco learns user/PC devices from:
- macwalk: MAC address table collection
- arpwalk: ARP/IP collection
- nbtwalk: optional Windows hostname detection

Recommended deployment.yml Configuration
----------------------------------------

device_auth:

macsuck_only:
  - '10.10.99.0/24'

arpnip_only:

nbtstat_only:

  - '10.10.30.0/24'
  - '10.10.40.0/24'

schedule:
  discoverall:

Replace YOUR_SNMP_COMMUNITY with your real SNMP read-only community string.

Schedule Explanation
--------------------
discoverall:

macwalk:

arpwalk:
- Runs ARP/IP collection every 50 minutes.
- Helps Netdisco match IP addresses with MAC addresses.

nbtwalk:
- Runs NetBIOS scan at 8:00 AM, 1:00 PM, and 9:00 PM.
- This is optional.

expire:

Delete Discovered Switches

~/bin/netdisco-do delete -d 10.10.99.4
